# RentSmart – Sistema de Locação de Imóveis

## 1. Descrição do projeto

O RentSmart é um sistema desenvolvido em Python para realizar orçamentos de locação de imóveis da R.M Imóveis.

O programa permite selecionar apartamentos, casas e estúdios, calcular valores de aluguel, adicionais, descontos e taxas contratuais.

## 2. Funcionalidades

- Seleção do tipo de imóvel.
- Cálculo do aluguel mensal.
- Adicionais por quantidade de quartos.
- Cálculo de garagem e estacionamento.
- Aplicação de descontos.
- Parcelamento da taxa contratual.
- Validação das informações digitadas.
- Geração automática de relatório CSV com projeção de 12 meses.

## 3. Tecnologias utilizadas

- Python 3
- Biblioteca CSV
- Programação Orientada a Objetos (POO)

## 4. Como executar

1. Instale o Python 3.
2. Abra a pasta do projeto no VS Code.
3. Abra o terminal.
4. Execute o comando:

```bash
python trabalho.py
```

5. Responda às perguntas apresentadas pelo sistema.
6. Visualize o orçamento gerado.

## 5. Arquivo CSV

Ao finalizar a execução, o sistema gera automaticamente o arquivo `projecao_rentsmart.csv`, contendo uma projeção financeira de 12 meses com aluguel, parcelas contratuais e total mensal.
